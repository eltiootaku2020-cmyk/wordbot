# Referencias visuales externas — reparto inicial de Isekai sin Destino

**Estado:** referencias visuales aprobadas por el usuario el 31-10-2026. No convierten las obras de origen en canon de Isekai sin Destino.  
**Alcance:** inspiración visual externa para Brina, Maelis y Sera. Se conservan las edades, profesiones, personalidades, capacidades y decisiones narrativas ya documentadas.

## Regla visual obligatoria para todos los personajes — confirmada 31-10-2026

Todas las imágenes representativas de personajes del proyecto deben tener **estética anime 2D** (ilustración anime/manga o arte de personaje de videojuego con lenguaje visual anime). Se permite generar las imágenes con IA siempre que el resultado respete esa dirección artística.

- **Permitido y preferido:** ilustración 2D anime, rasgos estilizados, expresividad propia del anime, lineart y sombreado ilustrado coherentes.
- **No permitido:** fotorealismo, hiperrealismo, fotografía, piel/rostros de apariencia realista ni renders 3D realistas o inquietantes.
- La regla se aplica a protagonistas, aventureros, PNJ, aliados, antagonistas y criaturas con diseño de personaje.
- Una referencia externa de otro estilo puede servir únicamente para estudiar rasgos generales como pose, silueta, paleta o composición. No se mostrará ni reutilizará directamente como imagen representativa si no cumple la estética anime.
- Las referencias actuales de Brina, Maelis y Sera **no son diseños finales ni autorizan un acabado realista**: cualquier adaptación o generación posterior deberá convertirse a ilustración anime 2D.
- Mantener una dirección artística coherente entre personajes; no mezclar retratos anime con imágenes hiperrealistas.

## Límites de uso y conservación

1. Las imágenes se registran como **referencias**, no como diseños finales aprobados al detalle. La selección de rasgos concretos (rostro, cabello, vestimenta, paleta, silueta) puede definirse más adelante. En todos los casos, el diseño final debe seguir la regla obligatoria de ilustración anime 2D indicada arriba.
2. No se copia ninguna biografía, nombre, personalidad, habilidad, especie o continuidad de los personajes de origen.
3. Las tres fichas actuales conservan íntegramente su canon. Solo se añade el vínculo visual y su atribución.
4. El repositorio almacena enlaces a las páginas de origen, no copias binarias de las imágenes. Los enlaces externos pueden cambiar o dejar de estar disponibles.
5. La referencia de BOOTH se conserva como vínculo a la página del recurso; no se descarga ni redistribuye el paquete. La página describe sus propias condiciones de uso, que deberán revisarse si en el futuro se decide adquirir o reutilizar algún archivo concreto.
6. Estas referencias no modifican el JSON de importación de SpicyChat: son metadatos de diseño para las fichas del proyecto, no contenido que el bot deba repetir durante una partida.
