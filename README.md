# Proyectos de bots de SpicyChat

Este repositorio contiene varios proyectos de historias. Cada uno tiene su propia carpeta, configuración, Lorebook y registro de decisiones. No mezclar el canon ni los archivos de proyectos distintos.

## Historias

- [Isekai sin Destino](proyectos/isekai-sin-destino/README.md) — fantasía abierta, supervivencia, Eco, cronología regional y continuidad de partida.
- [DanMachi](proyectos/danmachi/README.md) — aventura en Orario, Familias, Falna y Dungeon; varias decisiones iniciales siguen pendientes.

## Regla de organización

La rama \`docs/historias-organizadas\` es la vista organizada de los proyectos. Las ramas previas \`docs/isekai-spicychat-lorebook\` y \`docs/danmachi-spicychat\` se conservan como historial de trabajo, pero los nuevos cambios se deben aplicar a la carpeta del proyecto correspondiente en esta rama para evitar copias divergentes.
