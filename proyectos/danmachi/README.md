# DanMachi — bot de SpicyChat

**Estado:** configuración inicial v0.1, en desarrollo.  
**Rama organizada de trabajo:** \`docs/historias-organizadas\`  
**Carpeta:** \`proyectos/danmachi/\`

Este proyecto es independiente de Isekai sin Destino. No se deben mezclar sus personajes, reglas, poderes ni decisiones.

## Archivos

- \`SPICYCHAT_CONFIG.md\`: nombre, título, descripción, Personality, Scenario, Greeting, Example Dialogue y etiquetas sugeridas.
- \`LOREBOOK_ENTRIES.md\`: 26 entradas iniciales para añadir manualmente a una única Lorebook.
- \`DECISIONES_Y_CONTINUIDAD.md\`: decisiones confirmadas, valores provisionales y pendientes.
- \`PRUEBAS_DE_COHERENCIA.md\`: pruebas contra reinicios, poderes inventados, spoilers y pérdida de continuidad.

## Estado actual

La base representa una aventura de mundo abierto en Orario. Como punto de partida provisional, el protagonista es un aventurero adulto recién llegado, sin Familia, Falna ni poder original confirmado. El origen del protagonista, el punto exacto de canon y la posible habilidad especial siguen pendientes.

No está probada todavía en la cuenta de SpicyChat. El archivo Lorebook está en Markdown para carga manual; no se ha creado un JSON de importación con un esquema no verificado.
